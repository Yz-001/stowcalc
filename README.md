# stowcalc · 集装箱装柜估算

面向仓库现场装柜的**单文件网页工具**：录入箱型数据后，自动把纸箱排布到集装箱内，输出 3D 可视化、装柜顺序清单、分层俯视图与总体装柜方案。无需安装、无需后端，浏览器直接打开 `index.html` 即可使用。

## 快速开始

直接双击 `index.html`（推荐 Chrome / Edge）。页面为纯前端，所有计算在浏览器本地完成，数据不上传。

## 功能特性

- **柜型组合**：内置 20GP / 40GP / 40HQ / 45HQ，支持自定义内尺寸与载重，可多条柜组合。
- **两种录入方式**：
  - 导入 Excel（`子单导出` 格式，SheetJS 解析，cm 自动转 mm，自动补数量）；
  - 快速粘贴框，格式 `子单号,长,宽,高,重量`（逗号分隔）。
- **两级标识**：父运单号（整票同柜约束单位）+ 子单号（单个纸箱），图例可从运单展开到子单。
- **三种算法对比**：多策略贪心、遗传算法（GA）、模拟退火（SA）同时计算，标题右侧下拉框切换，每个方案标注「件数·柜数·利用率」，默认推荐最优。
- **可视化输出**：
  - 3D 装柜可视化（Three.js，可旋转/缩放，点击图例定位高亮）；
  - 装柜顺序表（仓库师傅照表从柜尾往里装、从下往上堆）；
  - 分层俯视图（数字=装柜顺序）；
  - 运单图例（点击定位，父运单可展开到子单）；
  - 总体方案：已装入 / 未装下运单、使用柜数、体积利用率、重量利用率。
- **整票同柜约束**：同一父运单的纸箱必须进同一条柜，不跨柜拆分；柜内不同运单混排填空。
- **大屏风格**：深色科技风、无滚动一屏布局、左侧面板可折叠、模块支持全屏查看。

## 算法说明

装箱采用**极值点（Extreme Point）角点搜索 + 6 朝向旋转**，上层对「装箱顺序」做搜索：

- **多策略贪心**：枚举多种排序（体积/最大边/底面积/高度降序、体积升序）取最优。
- **遗传算法**：顺序编码，OX 交叉 + 交换变异 + 精英保留。
- **模拟退火**：交换/翻转片段邻域，按温度概率接受劣解以跳出局部最优。

3D 装箱属于 NP-hard 问题，以上均为启发式近似，不保证数学绝对最优。

## 性能

- 计算在 **Web Worker** 后台线程执行，页面不卡顿；碰撞检测使用 1m 空间网格哈希。
- 3D 超过 80 箱自动改用 **InstancedMesh 合批渲染**（1 个 draw call）。
- 大数据量自动降级：总箱数 >120 缩减迭代，>300 时 GA/SA 退化为贪心。
- 实测 900 箱量级约 1 秒内完成。
